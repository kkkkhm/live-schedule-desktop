# 原生应用菜单实施计划

1. 新增菜单单元测试，覆盖菜单结构、命令白名单、帮助地址和 50%～200% 缩放边界。
2. 新增独立 `desktop/menu.js`，生成跨平台原生菜单模板并安装 Electron 应用菜单。
3. 在主进程启用可见菜单栏，注入菜单依赖并保持窗口生命周期安全。
4. 在预加载脚本暴露只读菜单命令订阅接口，过滤未知命令并支持取消订阅。
5. 在渲染页面将菜单命令映射到现有导入、导出和更新检查函数，并移除页面中重复的按钮和更新卡片。
6. 更新桌面安全测试和使用说明。
7. 运行全部逻辑与桌面测试、Windows 打包和桌面冒烟测试。
8. 提交实现；版本发布另行按用户指示执行。
