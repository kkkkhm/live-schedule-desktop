# 排班表与业绩表 Excel 导入导出实施计划

> 设计依据：`docs/superpowers/specs/2026-10-12-schedule-performance-excel-import-export-design.md`

## 实施原则

- 使用测试驱动方式逐步落地，每个任务先补失败测试，再实现最小功能并运行相关测试。
- 排班模板、展示版排班表和页面保存共用同一套时间、出勤与冲突校验，不在不同入口复制规则。
- Excel 解析先生成内存预览，用户确认后才事务式更新 `state`；任何阻断性错误都不得部分写入。
- 保留现有 JSON 备份、排班 CSV、时长统计、业绩排名和跨平台打包能力。
- 不提交 `.artifact-runtime/` 或临时预览文件。

## 任务一：建立出勤时间与直播区间的纯逻辑规则

**修改文件**

- `logic.js`
- `tests/logic.test.js`

**步骤**

1. 新增失败测试，覆盖直播开始时间早于 `11:00`、`11:00–15:59`、`16:00` 及以后对应的三个出勤区间。
2. 新增失败测试，覆盖直播开始早于出勤开始、结束晚于出勤结束、缺少起止时间和合法区间。
3. 在 `logic.js` 增加 `attendanceWindowForTime`、`validateLiveTimeRange` 和所需的分钟转换辅助函数，并通过 UMD API 导出。
4. 将现有排班冲突检查可复用地接入时间越界结果，保证后续页面和导入调用同一函数。
5. 运行 `node tests/logic.test.js`。

## 任务二：建立 Excel 领域模型、配置指纹和事务式合并

**新增/修改文件**

- 新增 `excel.js`
- 新增 `tests/excel.test.js`
- 修改 `package.json`
- 修改 `index.html`

**步骤**

1. 建立可同时在浏览器与 Node 中加载的 `excel.js` UMD 模块，并在 `index.html` 中于 `app.js` 前加载。
2. 新增测试数据工厂，覆盖人员、启用/停用班组、自定义班次、多个直播间、排班记录和业绩金额。
3. 实现稳定配置指纹：只纳入模板身份相关的启用班组、人员、班次和直播间 ID 与关键字段，排序后序列化并生成确定性摘要。
4. 实现当前状态到横向模板模型的转换，输出日期、班组、主播、副播、班次、直播间、直播时间、加班时间、备注和派生出勤时间。
5. 实现导入候选变更模型以及默认更新/完全覆盖两种合并策略；所有变更先作用于深拷贝，校验通过后才返回可提交状态。
6. 在 `package.json` 的 `test` 脚本加入 `node tests/excel.test.js`，并在 electron-builder 的 `files` 清单加入 `excel.js`。
7. 运行 `node tests/excel.test.js` 和 `npm test`。

## 任务三：生成横向动态排班模板

**修改文件**

- `excel.js`
- `tests/excel.test.js`

**步骤**

1. 新增测试，分别验证 1 天、7 天、14 天列数，以及启用班组和直播间数量变化后的行数。
2. 使用传入的 ExcelJS 创建 `排班填写表`、`填写说明`、`模板配置`、`可选项` 四个工作表。
3. 按当前启用的全部班组生成区域，不区分正式或兼职人员；每组生成出勤时间、班次、主播状态、副播状态、各直播间直播时间、加班时间和备注行。
4. 将日期、班组、人员、直播间名称和隐藏 ID 锁定；为班次和人员状态添加数据验证下拉；冻结日期与班组信息区域。
5. 在出勤时间单元格写入仅用于展示的 Excel 公式，程序导入时仍自行重新计算。
6. 写入模板类型、模板版本、配置指纹和每个可编辑单元格的隐藏映射；隐藏 `模板配置` 与 `可选项`。
7. 支持“空白模板”和“预填当前区间排班”两种生成模式。
8. 使用 ExcelJS 重新读取生成的缓冲区，断言工作表、隐藏状态、映射、数据验证、锁定属性和预填数据正确。

## 任务四：解析、校验并预览排班模板

**修改文件**

- `excel.js`
- `logic.js`
- `tests/excel.test.js`

**步骤**

1. 新增失败测试，覆盖模板版本错误、配置指纹过期、隐藏映射被修改、系统字段被移动或改名。
2. 解析 `排班填写表` 和 `模板配置`，按隐藏映射还原日期、班组、班次、人员状态、直播间时间、加班和备注。
3. 校验同一班组同一天最多一个直播间有直播时间；“本休”“调休”“未排班”不得同时存在直播或加班时间。
4. 调用任务一的出勤校验，阻止超出三个固定出勤区间的直播记录。
5. 校验主播副播相同、时间重叠、模板内休假冲突和与现有状态的冲突；分别产出阻断性错误与可确认警告。
6. 生成新增、更新、跳过数量及逐项变更摘要，并测试任一阻断错误都不会返回可提交状态。
7. 测试默认更新保留空白字段、完全覆盖允许清空可编辑字段、区间外排班和业绩金额始终不变。

## 任务五：生成并导入业绩模板

**修改文件**

- `excel.js`
- `tests/excel.test.js`

**步骤**

1. 新增测试，验证业绩模板包含日期、直播间名称、账号、班次、主播、副播、金额和系统记录标识。
2. 生成 `填写说明`、`业绩数据`、`可选项`，只导出已有有效排班记录。
3. 解析金额并校验非负数、最多两位小数、重复业务键、记录标识以及主播副播与现有排班一致。
4. 事务式更新 `performanceAmount`，保证人员、直播时间、加班、备注和排班模板数据不被改动。
5. 测试导入后主播与副播各自获得完整业绩金额，现有排名逻辑可以立即使用新金额。
