# 业绩录入矩阵简化设计

## 目标

将“业绩排名”页面上方的逐行录入表改为接近原排班表的横向矩阵，在不改变业绩数据和排名规则的前提下，提高查看与录入效率。

## 页面结构

- 业绩录入区采用“日期横向、班次纵向”的矩阵。
- 左侧固定四个班次：主号早班、主号中班、主号晚班、副直播间班次。
- 顶部只展示当前选择的 1–14 天日期区间，超过可视宽度时横向滚动。
- 日期表头和左侧班次列保持醒目，方便在大表中定位。
- 主播业绩榜和副播业绩榜继续显示在矩阵下方。

## 单元格内容

每个已排班单元格仅显示：

1. 直播间名称。
2. 主播姓名。
3. 副播姓名。
4. 业绩金额输入框。
5. 保存或校验状态。

不显示直播起止时间、直播时长、人员选择器和其他排班编辑控件。未排班单元格显示“未排班”，不提供业绩输入。

## 范围规则

- 录入矩阵始终跟随顶部当前日期区间，不受业绩快捷范围按钮影响。
- “当前区间、近30天、近3个月、全部”只控制下方主播榜和副播榜的统计范围。
- 切换快捷范围时不重建录入矩阵，只更新范围提示和两个排名表。

## 数据与保存

- 继续使用现有班次中的 `performanceAmount` 和 `performanceUpdatedAt` 字段，不迁移或复制数据。
- 金额仍为非负人民币金额，最多两位小数。
- 修改金额后自动保存，并即时更新当前所选范围的主播榜和副播榜。
- 排班人员变化、班次清空和排名归属规则保持现有实现不变。

## 响应式与交互

- 矩阵使用横向滚动，避免压缩 14 天列导致内容不可读。
- 日期列使用统一最小宽度；输入框控制在适合金额录入的紧凑宽度。
- 已保存、未录入和输入错误采用文字与颜色双重反馈。
- 排名区继续在窄屏下由双列切换为单列。

## 验收标准

- 当前日期区间的每一天都对应一个日期列。
- 四个班次都对应固定行，已排班信息出现在正确交叉单元格。
- 空班次不能录入业绩。
- 输入有效金额后自动保存，主播榜和副播榜同步更新。
- 快捷范围按钮只影响排名，不改变矩阵日期列。
- 原有业绩数据、排名规则和清空联动不受影响。

## 测试

- 保留现有金额校验、范围计算和排名计算单元测试。
- 新增或调整页面结构检查，确认矩阵表头、班次行和业绩输入绑定正确。
- 运行 JavaScript 语法检查、完整逻辑测试和压缩包内容检查。
