# 排班与业绩 Excel 导入模板设计

## 交付物

提供两个独立的 Excel 文件：排班导入模板和业绩导入模板。本阶段只确认模板，不修改应用代码。

## 排班导入模板

主工作表名为“排班填写表”。日期横向排列，每列一天，支持 1–14 天；班组纵向排列，每个班组占一个连续区块。左侧两列固定显示项目与人员或直播间名称，日期从第三列开始。

每个班组区块按以下顺序排列：

1. 班组出勤时间：系统根据总直播时间自动计算，锁定。
2. 班次：从启用班次中下拉选择。
3. 主播：左侧显示班组主播姓名；日期单元格选择正常、本休、调休或未排班。
4. 副播：左侧显示班组副播姓名；日期单元格选择正常、本休、调休或未排班。
5. 直播时间：每个启用直播间各占一行；同一班组同一天只允许填写一个直播间。
6. 加播提示：根据班次正常时段和总直播时间自动显示“前加播 Xh”或“后加播 Xh”，锁定。
7. 备注：可选文本。

直播时间使用 `HH:MM-HH:MM`，填写包含加播后的完整连续区间。正常直播时长最多按设置中的默认正常直播时长计算，超出的连续部分计入加播。总直播区间不得超出出勤时间，也不得超过每班最大允许加班时长。

黄色单元格为用户输入区域，蓝灰色单元格为锁定的系统或公式区域。不同班组使用不同浅色背景，休假状态使用绿色，加播提示使用红色。冻结左侧说明列和顶部日期行。

工作簿包含：

- 排班填写表
- 填写说明
- 模板配置（隐藏）
- 可选项（隐藏）

隐藏工作表保存模板版本、配置指纹以及班组、人员、班次和直播间的系统 ID。显示名称只用于人工核对。

## 业绩导入模板

主工作表名为“业绩数据”，每个已保存的排班班次占一行。字段顺序为：

1. 日期
2. 直播间
3. 账号
4. 班次
5. 主播
6. 副播
7. 总直播时间
8. 业绩金额（元）
9. 备注
10. 系统记录标识

只有业绩金额和备注允许编辑。金额必须为非负数，最多两位小数。空金额表示不更新原业绩，数值 0 表示明确将业绩改为零。主播、副播、日期、班次和系统记录标识锁定；导入时依靠系统记录标识定位排班，并校验人员信息是否仍与当前排班一致。

工作簿包含：

- 业绩数据
- 填写说明
- 模板配置（隐藏）

## 样稿内容

排班样稿使用 7 天、4 个班组、2 个直播间展示横向结构，填入少量正常班次、休假和前后加播示例。业绩样稿使用同一批示例排班生成逐班记录，填入少量金额示例，以便检查格式、锁定区域和金额精度。
