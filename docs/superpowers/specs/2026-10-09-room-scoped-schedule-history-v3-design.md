# 直播间独立周排班与历史记录 V3 设计

## 目标

将当前“每个排班格选择直播间”的模式改为“一张周排班表统一服务于一个直播间”。用户可切换直播间查看各自独立周表，并可从近三个月历史中复制排班到新的周次继续编辑。

## 导航与周排班界面

顶部标签顺序调整为：

1. 周排班
2. 历史记录
3. 直播间管理
4. 人员管理
5. 时长统计

“周排班”标题右侧显示直播间选择框。每个普通班、加班排班格内不再显示直播间选择。

未选择直播间时，不创建或修改排班数据，表格显示禁用状态并提示“请先选择直播间”。选择直播间后，当前周只加载该直播间对应的周表。切换直播间后，周次不变，表格切换为目标直播间的独立排班。

停用的直播间不用于新周表选择；若当前或历史周表已绑定停用、删除的直播间，仍通过名称与账号快照显示。

## 数据模型

数据版本升级为 V3。排班以“直播间 ID + 周一日期”为唯一维度：

```text
schedules[roomScheduleKey][weekKey]
  roomId
  roomNameSnapshot
  roomAccountSnapshot
  days
    monday ... sunday
      morning
      overtimeMorning
      afternoon
      overtimeAfternoon
      evening
      overtimeEvening
      leavePeople
  createdAt
  updatedAt
```

`roomScheduleKey`使用直播间 ID；无法可靠归属直播间的旧数据使用固定兼容键`unassigned`。`weekKey`始终为目标周的周一日期。

班次记录继续保存人员名称快照，周表保存直播间名称和账号快照。删除人员或直播间不会破坏历史记录。

## V2 到 V3 迁移

升级前把原始 V2 JSON 保存到独立浏览器备份键，迁移成功后才覆盖主存储。

- 若旧周表所有已排班格都属于同一个非空直播间，整周自动归入该直播间。
- 若旧周表包含多个直播间，归入`unassigned`。
- 若旧周表没有任何直播间，归入`unassigned`。
- 移除班次级直播间字段前，将直播间名称和账号保存为周表快照。
- 原有人员、时间、备注、加班、休假和统计数据原样保留。
- V1 导入先执行 V1→V2 迁移，再执行 V2→V3 迁移。
- 迁移失败时不得覆盖旧主存储。

## 历史记录

历史记录只展示从当前日期向前推三个月至今天的周表，不删除更早数据。列表按周日期倒序排列，并支持按直播间筛选。

每条记录显示：

- 直播间名称与账号
- 周日期范围
- 有效直播场次
- 最后修改时间
- “查看”操作
- “复制到新日期”操作

“查看”会切换到对应直播间和周次并打开周排班标签。

## 复制到新日期

用户选择目标日期，系统自动换算为目标周的周一。复制目标固定为历史记录所属直播间。

默认复制完整周表，包括：

- 主播、副播及人员快照
- 普通班和加班班次
- 开始与结束时间
- 备注
- 每日休假人员

复制对话区域提供“清空排班内容”复选框。选中后只创建目标直播间的空白周表，不复制人员、时间、备注和休假信息；空白普通班使用默认时间，加班时间为空。

若目标直播间的目标周已经存在任何排班内容或休假选择，禁止覆盖并显示明确警告。用户必须改选空白周。

复制成功后自动跳转到目标直播间、目标周和周排班标签，用户可以继续编辑。原历史记录始终保留。

## 统计与导出

时长统计基于当前选择的直播间和周次，只统计该周表的数据。统计口径保持不变：直播时长、加班时长、总时长，不区分主播与副播。

排班 CSV 仅导出当前直播间、当前周。直播间名称和账号来自周表快照或当前直播间主数据。JSON 导入导出支持 V1、V2、V3。

## 错误处理

- 未选择直播间时禁止编辑，并提供可见提示。
- 复制目标已有排班时禁止覆盖。
- 无效 JSON 或迁移失败时保留当前数据并显示错误。
- 历史记录引用已删除人员或直播间时显示历史快照。
- 自动保存失败时继续提示用户导出 JSON 备份。

## 测试与验收

自动测试覆盖：

- V2→V3 单直播间迁移。
- V2→V3 多直播间或空直播间迁移到`unassigned`。
- 不同直播间同一周的数据隔离。
- 近三个月历史范围与倒序排序。
- 完整复制保留所有排班内容。
- 清空复制创建默认空白周表。
- 目标周已有内容时禁止覆盖。
- 普通直播、加班统计与休假冲突继续正确。

浏览器验收覆盖：

- 直播间选择框位于“周排班”标题右侧。
- 班次格不再包含直播间选择。
- 切换直播间显示各自独立周表。
- 历史筛选、查看、复制和清空选项可用。
- 复制成功后可直接编辑且原历史记录不变。
- 页面无控制台错误。
