# 每周直播排班工具 V2 升级设计

## 升级目标

在现有本地网页工具上增加直播间管理、加班排班、休假管理、人员删除和新的时长统计口径。升级必须保留浏览器中已有的人员与普通班排班。

## 导航结构

标签页顺序调整为：

1. 周排班
2. 直播间管理
3. 人员管理
4. 时长统计

数据导入、导出功能保持在页面顶部。

## 周排班

### 行结构

排班表按以下顺序显示七行：

1. 早班
2. 加班
3. 中班
4. 加班
5. 晚班
6. 加班
7. 休假人员

三个加班行名称相同，分别位于早班、中班、晚班之后。它们都是独立排班记录，不使用“早班加班”等名称。

### 排班字段

每个普通班和加班单元格按以下顺序显示：

- 直播间
- 主播
- 副播
- 开始时间
- 结束时间
- 自动计算时长
- 备注

直播间下拉框显示为`直播间名称（账号）`，只列出启用的直播间；历史排班引用的停用或已删除直播间仍作为历史选项显示。

普通班时长计入直播时长。三个加班行的时长均计入加班时长。

### 休假人员

- 每天的休假单元格提供可多选的人员清单。
- 清单默认显示启用人员；历史休假记录中的停用或已删除人员继续显示。
- 同一人员如果既被标记为当天休假，又出现在当天任何普通班或加班排班中，显示冲突警告。
- 休假记录不产生直播时长或加班时长。

## 直播间管理

直播间字段包括：

- 直播间名称
- 账号
- 状态
- 操作

支持以下操作：

- 新增直播间
- 编辑名称和账号
- 停用或启用
- 删除

直播间名称和账号均不能为空。同一账号不允许重复创建。

删除前显示二次确认。删除后从直播间主数据中移除，但历史排班中的直播间名称和账号快照继续保留。

## 人员管理

保留现有表单和列表结构，增加`用工类型`字段，可选择：

- 正式员工
- 兼职

操作按钮顺序为：编辑、停用/启用、删除。

删除前显示二次确认。删除后从人员主数据中移除，但历史排班和休假记录中的姓名快照继续保留。

## 时长统计

统计不再区分主播和副播身份。每个人显示：

- 直播时长：该人员参与所有普通班的时长合计。
- 加班时长：该人员参与所有加班行的时长合计。
- 总时长：直播时长加加班时长。

同一场中主播与副播不能是同一人。如果异常数据中出现同一人担任两个角色，该场只计一次时长，同时显示冲突警告。

## 冲突检查

保留并扩展以下检查：

- 同一场主播和副播为同一人。
- 同一人员在同一天的两个时间重叠场次中出现。
- 已安排人员但起止时间无效。
- 被标记休假的人员仍出现在当天排班中。

普通班与加班之间、不同加班行之间均参与时间重叠检查。

## V1 到 V2 数据迁移

- 数据版本从`1`升级为`2`。
- 已有人员增加`employmentType: formal`，之后可在人员管理中修改。
- 增加空的`rooms`数组。
- 已有早、中、晚班记录原样保留，并增加空的直播间字段。
- 每天新增三个空的加班记录和空的休假人员数组。
- 姓名快照继续沿用已有数据。
- 迁移成功后保存为 V2；如果迁移异常，保留原始存储内容并显示错误，不用空数据覆盖。

## 导入导出

- JSON 导出使用 V2 数据结构。
- 导入支持 V2，也支持自动迁移合法的 V1 备份。
- 排班 CSV 增加直播间、排班类型和用工类型相关信息。
- 时长统计 CSV 改为直播时长、加班时长、总时长。

## 验收标准

- 周表准确显示三组普通班和三组独立加班行。
- 每个普通班和加班格均可独立选择直播间、主播、副播和时间。
- 直播间可以新增、编辑、停用、启用和删除。
- 人员可以设置正式员工或兼职，并可以删除。
- 删除人员或直播间后，历史排班仍显示对应快照。
- 每天可以多选休假人员，休假与排班冲突会被标记。
- 统计准确输出每人的直播时长、加班时长和总时长。
- V1 本地数据及 V1 JSON 备份可无损升级。
