# 排班表与业绩表 Excel 导入导出设计

## 目标

为直播排班桌面工具增加基于固定 Excel 模板的排班与业绩导入导出能力。用户可以导出当前数据或空白模板，在 Excel 中填写或修改后重新导入。导入前必须预览变更并完成校验，避免覆盖无关数据或因名称错误生成重复人员。

排班同时增加系统计算的出勤时间。出勤时间由直播时间自动确定，用户不单独填写；直播时间必须完整落在对应出勤区间内。

现有 JSON 全量备份继续保留，用于完整迁移和恢复；Excel 功能用于日常业务录入和交换。

## 累积设计范围

本设计是前两版方案的合并升级，实施时不得只实现最新的横向模板而遗漏既有能力：

1. 保留第一版的排班表与业绩表 Excel 导入导出、固定模板、导入预览、默认更新与完全覆盖、事务式写入、JSON 备份以及主播/副播业绩排名刷新。
2. 保留第二版的三个固定出勤区间、根据直播时间自动计算出勤时间，以及直播时间不得超出出勤区间的保存、自动排班和导入校验。
3. 将排班导入模板升级为本次确认的横向动态矩阵，并新增与导入模板分离的纵向展示版排班表。

因此，后续实现、测试和验收统一以本文档当前版本为准；前两版中与横向动态模板冲突的旧平铺排班结构不再采用，其余规则全部继续有效。

## 功能入口

桌面端“文件”菜单提供：

- 导入排班模板
- 导出可编辑排班模板
- 下载空白排班模板
- 导出展示版排班表
- 导入业绩表
- 导出业绩表
- 下载空白业绩模板
- 导入 JSON 备份
- 导出 JSON 备份
- 导出时长统计 CSV

排班和业绩的导入流程统一为：

1. 选择 `.xlsx` 文件。
2. 检查工作簿和字段结构。
3. 解析、匹配并校验数据。
4. 显示导入预览。
5. 用户选择默认更新或完全覆盖。
6. 用户确认后一次性写入。
7. 自动保存并刷新排班、历史记录、统计和排名。

## Excel 模板

### 排班模板

排班模板采用“日期横向、班组纵向”的矩阵布局。用户先在软件中维护班组、人员、班次和直播间，再从当前选择的 `1–14 天`日期区间生成空白模板。

工作簿包含：

- `排班填写表`：用户可见的横向排班矩阵。
- `填写说明`：时间格式、颜色含义、更新模式和导入规则。
- `模板配置`：模板版本、配置指纹、日期、班组、人员、班次、直播间和单元格映射；默认隐藏。
- `可选项`：班次与人员状态的 Excel 下拉来源；默认隐藏。

`排班填写表`顶部按列显示星期和具体日期。日期来自生成模板时软件当前选择的区间；导入只处理这些日期，不影响区间外排班。

左侧按软件中当前启用的全部班组自动生成区域，不再按“正式”或“兼职”限制人员访问，班组数量不固定。每个班组区域包含：

1. 班组出勤时间：根据当日直播时间自动计算，只读。
2. 班次：从当前启用班次中选择，也可选择“本休”“调休”或“未排班”。
3. 主播状态：左侧显示配置中的主播姓名，日期单元格默认跟随班次，也可单独选择“本休”或“调休”。
4. 副播状态：左侧显示配置中的副播姓名，规则与主播状态相同。
5. 直播时间：每个当前启用直播间各占一行，使用 `HH:MM-HH:MM` 格式。
6. 加班时间：使用 `HH:MM-HH:MM` 格式。
7. 备注：用于填写加班原因或临时调整。

班组名称、主播姓名、副播姓名、直播间名称、日期和隐藏ID由软件生成并锁定。班次、主播状态、副播状态、直播时间、加班时间和备注为可填写区域。

同一班组同一天只能选择一个班次，并且只能有一个直播间的直播时间非空。同时填写多个直播间属于阻断性错误。选择“本休”“调休”或“未排班”时，直播时间和加班时间必须为空。

主播或副播单独选择“本休”或“调休”，但该班组仍填写直播时间时，导入预览显示人员休假冲突，必须先在软件中调整班组或排班后才能导入。

模板用颜色区分班组区域、可编辑单元格、系统字段、休假和错误。冻结顶部日期行和左侧班组信息，便于横向查看十四天排班。工作表保护不设置密码，仅用于防止误改系统字段；如果系统字段或结构被修改，导入将被拒绝。

### 展示版排班表

展示版排班表与导入模板分开。它按日期纵向分组，包含“日期、账号、班次、班组、直播时间、出勤时间、直播时长”七列。日期和账号按连续记录合并，休假行使用黄色区分，跨日休假与临时调整备注使用独立色带。标题显示导出日期区间，表格适合直接查看、打印和分享。

展示版排班表不包含隐藏映射，不作为导入文件。需要修改后重新导入时，应使用“导出可编辑排班模板”。

### 业绩模板

工作簿包含：

- `填写说明`
- `业绩数据`
- `可选项`

`业绩数据`包含以下列：

1. 日期
2. 直播间名称
3. 直播间账号
4. 班次
5. 主播
6. 副播
7. 业绩金额
8. 系统记录标识

业绩金额单位为人民币元，必须大于或等于零，最多保留两位小数。主播和副播字段用于核对当前排班，不用于改变排班人员。

### 模板行为

- “导出可编辑排班模板”使用与空白模板相同的横向结构，并预填当前日期区间的已有排班；修改后可以重新导入。
- “导出展示版排班表”采用已确认的按日期纵向分组样式，适合查看、打印和分享，不作为导入文件。
- 两种排班 Excel 输出使用同一份当前排班数据和同一套出勤时间计算规则：可编辑模板用于修改后重新导入，展示版用于查看、打印和分享。
- 导出的现有业绩文件可以直接修改后重新导入。
- 排班模板根据生成时启用的班组和直播间自动增减行，根据当前选择的日期区间自动增减列。
- 排班导出与排班模板均展示系统计算后的出勤时间，但不提供可编辑的出勤时间字段。
- 排班模板不包含业绩金额，导入排班不得改变已有业绩。
- 业绩模板只更新业绩金额，不修改人员、直播时间、加班或备注。
- Windows 和 macOS 使用完全相同的模板格式。
- 模板在工作簿中写入模板类型、模板版本和配置指纹；程序只接受兼容版本且班组、人员、班次和直播间配置未过期的模板。

## 记录匹配

排班模板导入通过隐藏的`模板配置`工作表，将每个可编辑单元格映射到日期、班组ID、人员ID和直播间ID。班次下拉值再匹配当前启用班次ID。导入不依赖可见标题、颜色或合并单元格推断身份。

业绩模板仍优先使用系统记录标识；没有标识时使用“日期＋直播间账号＋班次”作为业务唯一键。

导入不自动创建人员、直播间或班次。当前配置与模板配置指纹不一致，或隐藏映射与可见系统字段不一致时，视为模板已过期或被篡改，阻止导入并要求重新下载模板。

## 校验规则

### 文件与格式校验

- 文件扩展名必须为 `.xlsx`。
- 必须存在目标数据工作表、模板配置、兼容的模板版本和完整单元格映射。
- 日期必须是有效日历日期。
- 时间必须使用有效的 24 小时格式。
- 业绩金额必须是有效的非负数，最多两位小数。
- 排班填写表的日期列、班组区域、直播间行和受保护的系统字段不得被删除、移动或改名。

### 数据匹配校验

- 排班模板中的班组、主播、副播、直播间和班次ID必须与当前系统配置一致。
- 模板配置指纹必须与当前启用配置一致。
- 排班模板中的单元格映射不得重复指向同一“日期＋班组＋字段＋直播间”组合。
- 业绩模板中不得出现重复的业务唯一键。
- 主播、副播名称与已匹配排班不一致时，业绩导入显示阻断性错误。

### 业务校验

- 主播和副播不能是同一人。
- 结束时间必须晚于开始时间；加班时间同样适用。
- 直播时间必须完整落在系统确定的出勤区间内。
- 同一班组同一天只能填写一个直播间的直播时间。
- 选择“本休”“调休”或“未排班”时不得填写直播时间或加班时间。
- 主播或副播处于“本休”或“调休”状态时，该班组不得继续排班。
- 检查同一人员的时间重叠。
- 检查休假人员当天仍被排班的冲突。

文件结构错误、数据无法匹配、重复记录、无效时间，以及同一模板中“人员休假但班组仍直播”的自相矛盾属于阻断性错误。与系统中其他排班产生的人员时间重叠或既有休假冲突属于业务警告，用户明确确认后可以继续导入。

## 出勤时间规则

系统只使用以下三个出勤区间：

- 直播开始时间早于 `11:00`：出勤时间为 `08:00–16:00`。
- 直播开始时间在 `11:00–15:59`：出勤时间为 `11:00–19:00`。
- 直播开始时间在 `16:00` 及以后：出勤时间为 `16:00–23:30`。

直播开始时间不得早于对应出勤开始时间，直播结束时间不得晚于对应出勤结束时间。如果直播时间无法完整落在系统选定的出勤区间内，则该记录无效并禁止保存、自动排班或导入。

出勤时间是派生值，不作为独立状态保存。修改直播时间后，页面显示、排班模板和 Excel 导出都重新计算出勤时间。Excel 导入不得单独设置或覆盖出勤时间。程序导入时重新计算出勤区间，不信任工作簿中的公式结果。

## 更新策略

默认使用“只更新已填写字段”模式：

- Excel 单元格有值时更新对应字段。
- Excel 单元格为空时保留系统原值。
- 找不到已有记录时新增。
- 内容完全相同时跳过。

预览中提供“完全覆盖重复记录”选项。启用后，重复记录中的空白可清空对应排班字段。以下数据始终保持独立：

- 排班导入不改变业绩金额。
- 业绩导入不改变排班内容。
- 休假信息只由排班模板中的主播状态和副播状态更新。

日期、班组和模板配置是记录身份字段，任何更新模式下都不能修改。完全覆盖模式允许清空班次、主播与副播状态、普通与加班时间和备注；它仍不得通过修改隐藏映射把一条记录移动到另一个日期或班组。

导入必须采用事务式处理：先在内存副本中应用所有变更和校验，全部通过后再替换当前状态并保存。任一阻断性错误都会取消整次导入，原数据保持不变。

## 导入预览

导入预览对话框显示：

- 文件名和目标类型。
- 总行数。
- 新增、更新、跳过的数量。
- 阻断性错误列表。
- 业务警告列表。
- 更新模式选择。

存在阻断性错误时禁用“确认导入”。只有业务警告时允许用户明确确认后继续。

导入成功后显示摘要，并立即：

- 刷新当前排班表。
- 同步历史记录与排班总览。
- 重新计算时长统计和主播、副播业绩排名。
- 将更新后的状态自动保存到本地。

## 程序结构

实现划分为三个职责明确的模块：

1. Excel 模板模块：按当前日期区间、启用班组和启用直播间生成横向排班模板，生成业绩模板，并导出当前数据与可选项。
2. Excel 解析与校验模块：验证模板版本和配置指纹，读取单元格映射，标准化日期时间和金额，计算并校验出勤区间，再生成预览结果。
3. 导入执行模块：在状态副本上按选定策略新增或更新，完成最终校验后提交状态。

桌面原生菜单只发送受限命令给渲染进程。文件选择仍通过隐藏的文件输入控件完成，Excel 读写复用项目现有的 ExcelJS 能力。业务逻辑和 DOM 展示分离，解析与合并函数保持可独立测试。

## 错误处理

- 无法读取或损坏的工作簿：显示明确错误，不修改数据。
- 模板版本不兼容：提示重新下载最新模板。
- 配置指纹不一致：提示班组、人员、班次或直播间配置已变化，要求重新下载模板。
- 工作表、映射、日期列或班组区域缺失：列出缺失项目。
- 匹配失败：显示行号、字段和值。
- 导入执行异常：回滚整次导入并保留原数据。
- 保存失败：提示用户导出 JSON 备份，不宣称导入成功。

## 测试与验收

自动化测试至少覆盖：

- 排班模板导出后原样导回不会产生变更。
- 当前日期区间为 1 天、7 天和 14 天时均能生成正确列数。
- 当前启用班组和直播间数量变化时，模板区域和直播时间行会同步增减。
- 班次下拉、主播与副播状态下拉、锁定字段、冻结窗格和隐藏映射正确生成。
- 修改排班模板后正确新增和更新记录。
- 业绩模板修改金额后正确更新主播和副播排名。
- 默认模式下空白单元格不清空已有值。
- 完全覆盖模式可以清空允许清空的排班字段。
- 排班导入不改变业绩，业绩导入不改变排班。
- 不存在的人员、直播间和班次会阻止导入。
- 重复记录、无效日期、无效时间和无效金额会阻止导入。
- 同一班组同一天填写多个直播间时阻止导入。
- 本休、调休或未排班状态仍填写直播与加班时间时阻止导入。
- 模板结构或隐藏ID被修改、配置指纹过期时阻止导入。
- 三种直播开始时段均能得到正确的出勤区间。
- 直播开始或结束时间超出对应出勤区间时，保存、自动排班和导入均会被阻止。
- 修改直播时间后，页面和 Excel 导出的出勤时间会同步更新。
- 时间重叠和休假冲突会产生可确认的警告。
- 导入失败时原状态不变。
- Windows 和 macOS 生成的模板结构一致。

人工验收包括：在软件中配置不同数量的班组和直播间，分别生成一至十四天的横向排班模板；在 Windows Excel、macOS Excel 和 WPS 中填写后重新导入，检查预览、自动保存、历史记录、排班总览、时长统计和业绩排名均正确刷新。

## 非目标

本次不支持任意第三方 Excel 格式自动识别，不在导入时自动创建人员、直播间或班次，也不提供云端多人协作或在线同步。
