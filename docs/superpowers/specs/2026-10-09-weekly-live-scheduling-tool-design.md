# 每周直播排班工具设计

## 目标

实现一个无需安装的本地网页工具，以日期横排、班次竖排的周课表形式安排主播和副播，并提供人员管理、时长统计及数据备份功能。

## 使用方式

- 用户双击 `index.html`，在现代桌面浏览器中运行。
- 工具不依赖服务器、账号或网络。
- 数据保存在当前浏览器的 `localStorage` 中。
- 用户可导出 JSON 备份，并在相同或其他浏览器中重新导入。

## 初版范围

### 周排班

- 用户通过周选择器选择一个自然周。
- 界面自动计算并显示周一至周日的日期。
- 行固定为早班、中班、晚班。
- 每个排班单元格包含：
  - 主播选择；
  - 副播选择；
  - 开始时间；
  - 结束时间；
  - 自动计算的直播时长；
  - 可选备注。
- 默认时间为：早班 `08:00-13:00`、中班 `13:00-18:00`、晚班 `18:30-23:30`，每个单元格均可修改。
- 未排班的单元格保持空白，不计入统计。

### 人员管理

- 可新增、编辑、停用人员。
- 首次运行预置参考表中的人员：程程、胖金、塔塔、阿怪、妍妍、江江、小珂、文慧；用户可自行调整角色或停用。
- 人员字段包括姓名、角色能力和启用状态。
- 角色能力支持主播、副播或两者兼任。
- 已停用人员不会出现在新的排班下拉框中，但历史排班和历史统计仍保留其姓名。
- 人员姓名不可为空；同名人员不允许重复创建。

### 时长统计

- 默认统计当前所选自然周。
- 每人显示主播时长、副播时长和总时长。
- 单场直播时长由结束时间减开始时间计算。
- 跨午夜场次按结束时间为次日计算。
- 缺少开始或结束时间时，该场不计时并显示数据提示。

### 冲突检查

- 同一人员在同一天的两个重叠时间段中被安排时显示冲突警告。
- 主播和副播身份均参与冲突检查。
- 同一场中主播和副播不能选择同一个人。

### 数据导入导出

- 导出完整 JSON：包含版本、人员、各周排班和设置。
- 导入 JSON 前验证格式；合法数据替换当前本地数据。
- 导入属于覆盖操作，界面在执行前要求用户确认。
- 可分别导出当前周排班 CSV 和当前周时长统计 CSV。

## 界面结构

页面顶部显示工具名称、周选择器、上一周、下一周和回到本周按钮。

主体使用三个标签页：

1. `周排班`：七列日期、三行班次的主编辑区域。
2. `人员管理`：人员列表和新增/编辑表单。
3. `时长统计`：当前周人员时长汇总及冲突列表。

页面右上角提供 JSON 导入、JSON 导出、排班 CSV 和统计 CSV 操作。

## 数据模型

```text
AppData
  version
  people[]
    id
    name
    canHost
    canCoHost
    active
  schedules
    YYYY-MM-DD（周一）
      monday..sunday
        morning|afternoon|evening
          hostId
          coHostId
          hostNameSnapshot
          coHostNameSnapshot
          startTime
          endTime
          note
```

周数据使用该周周一的 ISO 日期作为键。历史姓名快照保证人员改名或停用后，旧排班仍可解释。

## 数据流

1. 用户选择日期，程序换算到该周周一。
2. 程序读取对应周的数据并渲染课表。
3. 用户修改任意字段后，程序校验并立即写入 `localStorage`。
4. 统计模块从当前周排班重新计算时长，不保存重复汇总数据。
5. 冲突模块从当前周全部直播时段重新计算重叠关系。

## 错误处理

- 浏览器存储不可用时，页面显示明确提示，仍允许临时编辑和 JSON 导出。
- 无效导入文件不会修改现有数据。
- 时间格式无效、起止时间缺失或同场角色重复时，单元格显示错误状态。
- CSV 内容按 UTF-8 BOM 输出，便于中文 Excel 正确打开。

## 视觉规则

- 延续参考表格的“日期横向、班次纵向”结构。
- 周一至周日保持固定顺序。
- 表头使用清晰的浅色分区，不依赖颜色表达唯一含义。
- 当前日期、冲突和无效数据有独立状态提示。
- 窄屏允许横向滚动，不压缩到不可读。

## 验收标准

- 可选择任意周，并准确显示该周周一至周日日期。
- 可在任意日期和班次中选择主播、副播及时间，刷新页面后数据仍存在。
- 新增或停用人员后，下拉列表立即更新且历史记录不丢失。
- 统计结果能正确区分主播、副播和总时长。
- 同一人员的重叠排班会被标记。
- JSON 导出后重新导入能完整恢复人员和排班。
- 排班和统计 CSV 可由 Excel 正确打开并显示中文。

## 初版不包含

- 登录、权限、审批流和多人协作。
- 云同步、移动端应用和数据库服务。
- 多直播间或多账号维度。
- 拖拽排班、循环排班模板和工资计算。
