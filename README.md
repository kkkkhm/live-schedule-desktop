# 直播周排班工具

这是一个纯本地网页工具，用于按任意 1–14 天日期区间安排直播间、主播和副播，并分别统计普通直播时长、加班时长和总时长。

## 使用方法

1. 双击 `index.html`。
2. 使用顶部的开始日期和结束日期选择任意 1–14 天区间；左右按钮会按当前区间长度前后移动。
3. 先在“直播间管理”中维护直播间名称和账号。
4. 在“周排班”标题右侧选择直播间；一整张区间排班表只属于该直播间，切换直播间会切换到独立排班表。
5. 在排班格中选择主播、副播并设置直播时间；三个“加班”行均可独立排班。
6. 在“历史记录”按直播间和日期区间调出排班；点击“更新近三月总览排班表”可汇总最近三个月的每日记录。
7. 在“人员管理”中维护角色、正式/兼职状态，并可编辑、停用或删除。
8. 在最下方“休假人员”行按天多选休假人员，并可填写当天统一的休假备注。
9. 在“时长统计”中查看当前直播间的直播时长、加班时长、总时长和冲突提示。

数据会自动保存在当前浏览器中。建议定期点击“导出备份”保存 JSON 文件；更换电脑或浏览器后，可通过“导入备份”恢复。

本版本附带 `三个月测试排班-V4.json`。需要重新载入示例数据时，点击“导入备份”选择该文件即可（导入会覆盖浏览器中的当前数据）。

## 数据说明

- 早班正常时间：08:00–12:30
- 中班正常时间：13:00–17:30
- 晚班正常时间：19:00–23:30
- 超出正常班时间的直播部分拆分到对应“加班”行统计。
- 三个加班行不预设时间，排入后全部计入“加班时长”。
- 结束时间早于开始时间时，按跨午夜直播计算。
- 同一人员重叠排班、主播副播选为同一人、休假当天仍被排班时都会显示警告。
- 删除人员或直播间只会移出未来选择列表，历史排班中的名称和账号快照会保留。
- 旧版 V1/V2/V3 数据会自动升级到 V4，并在浏览器中保留升级前备份。
- V4 以“直播间 + 具体日期”保存数据，同一天从任何日期区间打开时都会显示同一份排班。
- CSV 文件带 UTF-8 BOM，可直接用中文 Excel 打开。

## 文件

- `app.js`：页面交互和本地存储
