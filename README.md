# 直播周排班工具

这是一个纯本地网页工具，用于按任意 1–14 天日期区间安排直播间、主播和副播，并分别统计普通直播时长、加班时长和总时长。

## 使用方法

1. 双击 `index.html`。
2. 点击顶部“选择日期区间”，像酒店订房一样先选开始日期、再选结束日期；最多连续选择 14 天。左右按钮会按当前区间长度前后移动。
3. 先在“直播间管理”中维护直播间名称和账号。
4. 周排班不再显示单独的直播间选择；直播间归属由智能排班模板内部维护，原有历史数据仍按直播间保留。
5. 展开“智能排班 · 四组正式班组＋固定兼职班组”，配置四组正式班组和一组固定兼职班组。固定兼职班组可从人员管理中所有已启用、且具备对应角色的主播或副播中选择。
6. 系统会逐日避开休假人员：4组正式班组可用时直接排满；3组可用时，固定兼职班组自动补唯一缺班；2组可用时，两组正式班组自动排早班和中班，固定兼职班组补晚班，副直播间当天留空。
7. 2组场景会自动在早班后填入 12:30–14:00、在中班后填入 17:30–19:00 的1.5小时加班，并备注“系统自动加班 1.5 小时”；加班时长独立统计。
8. 用户手动调整排班后，可点击“刷新系统提示”重新检查当前内容；刷新只更新提示，不覆盖任何人员、班次、直播时间或加班时间。
9. 编辑内容会自动保存；需要明确确认时，点击“保存排班”会立即保存并同步更新近三个月历史总览。
10. 在“历史记录”按直播间和日期区间调出排班；点击“更新近三月总览排班表”可汇总最近三个月的每日记录。
11. 在“人员管理”中维护角色、正式/兼职状态，并可编辑、停用或删除。排班格只显示人员、时间、加班和备注，班组类型与直播间由自动排班结果在后台保留。
12. 在最下方“休假人员”行按天多选休假人员，并可填写当天统一的休假备注。
13. 在“时长统计”中查看当前直播间的直播时长、加班时长、总时长和冲突提示。

数据会自动保存在当前浏览器中。建议定期点击“导出备份”保存 JSON 文件；更换电脑或浏览器后，可通过“导入备份”恢复。

本版本附带 `三个月测试排班-V8.json`。需要重新载入示例数据时，点击“导入备份”选择该文件即可（导入会覆盖浏览器中的当前数据）。

## 数据说明

- 早班正常时间：08:00–12:30
- 中班正常时间：13:00–17:30
- 晚班正常时间：19:00–23:30
- 副直播间班次默认时间：13:30–18:00，模板中可调整，但正常班次仍须为4.5小时。
- 加班时间填写在正常班次格内；2组场景由系统自动为两组正式班组各填入1.5小时加班。
- 3组场景由固定兼职班组补缺少的主号或副直播间班次；2组场景不排副直播间，由固定兼职班组补主号晚班。
- 固定兼职班组任一成员当天休假时不会自动寻找替补，系统会显示红色警告。
- 结束时间早于开始时间时，按跨午夜直播计算。
- 同一人员重叠排班、主播副播选为同一人、休假当天仍被排班时都会显示警告。
- 删除人员或直播间只会移出未来选择列表，历史排班中的名称和账号快照会保留。
- 旧版 V1/V2/V3 数据会自动升级到 V4，并在浏览器中保留升级前备份。
- V4 以“直播间 + 具体日期”保存数据，同一天从任何日期区间打开时都会显示同一份排班。
- CSV 文件带 UTF-8 BOM，可直接用中文 Excel 打开。

## 文件

- `index.html`：页面入口
- `styles.css`：界面样式
- `logic.js`：日期、时长、统计和冲突逻辑
- `app.js`：页面交互和本地存储
