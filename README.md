# 直播排班工具

这是一个纯本地网页工具，用于按任意 1–14 天日期区间安排直播间、主播和副播，并分别统计普通直播时长、加班时长和总时长。

## 独立桌面版

桌面版使用 Electron 完全离线运行，最终用户不需要安装 Node.js，也不需要启动本地服务器。

- Windows：运行 `npm run pack:win` 生成绿色便携版 EXE。
- macOS：在 macOS 环境运行 `npm run pack:mac`，分别生成 Intel（x64）和 Apple Silicon（arm64）未签名 ZIP。
- 桌面版左上角提供“文件 / 视图 / 帮助”原生菜单，可导入导出排班、业绩与 JSON 备份，缩放页面，检查更新和打开在线帮助。
- 自动构建：推送 `desktop-v*` 标签或手动运行 GitHub Actions 中的 `Build desktop apps`。

开发构建环境先执行 `npm install`。Windows 产物位于 `desktop-dist/LiveSchedule-Windows-1.0.9-x64.exe`。macOS 首次打开未签名应用时，如系统阻止运行，请进入“系统设置 → 隐私与安全性”，在安全提示处选择“仍要打开”。

桌面版不会在启动时自动联网。在“帮助 → 检查更新”中可手动检查公开的 GitHub Releases；发现新版本后，程序会用系统浏览器打开与当前 Windows、Intel Mac 或 Apple Silicon Mac 匹配的下载文件，不会自动覆盖本地版本。

浏览器版与桌面版的数据目录相互独立。迁移时先在旧版本点击“导出备份”，再在桌面版点击“导入备份”。

## 使用方法

1. 双击 `index.html`。
2. 点击顶部“选择日期区间”，像酒店订房一样先选开始日期、再选结束日期；最多连续选择 14 天。左右按钮会按当前区间长度前后移动。
3. 先在“直播间管理”中维护直播间名称和账号。
4. 在“排班设置”中统一维护班次、正式班组、固定兼职班组和每日最低目标；这套配置对所有直播间生效。
5. 班次最多 12 个，可自定义名称、默认直播间、起止时间、是否允许自动加班和加班优先级，也可排序、停用或删除；删除后的历史班次仍会保留。
6. 正式班组最多 12 个，可自定义名称、主播、副播和默认班次，也可排序、停用或删除。固定兼职班组独立设置，不区分正式或兼职，可选择所有已启用且具备对应主播或副播能力的人员。
7. 设置“最小班次数”“所有直播间当天最小直播总时长”和“默认自动加班时长”后，智能排班会先逐日排入无休假冲突的正式班组；班次数不足时优先用固定兼职班组补一个空缺班次，再按班次加班优先级补足总时长。
8. 每个正式班组每天最多安排一个完整班次；固定兼职班组每天最多自动补一个班次。可用班组或允许加班的容量仍不足时，系统会保留现状并提示人工处理。
9. 用户手动调整排班后，可点击“刷新系统提示”基于当前人员、休假、班次数量和加班时间重新评估；已解决的旧冲突会自动消除，刷新不会覆盖任何排班内容。
10. 编辑内容会自动保存；需要明确确认时，点击“保存排班”会立即保存并同步更新排班总览。
11. 在“历史记录”按直播间和日期区间调出排班；点击“更新排班总览”可汇总过去三个月及所有已保存的未来排班。
12. 在“人员管理”中维护角色、正式/兼职状态，并可编辑、停用或删除。排班格只显示人员、时间、加班和备注，班组类型与直播间由自动排班结果在后台保留。
13. 在最下方“休假人员”行按天多选休假人员，并可填写当天统一的休假备注。
14. 在“时长统计”中查看当前直播间的直播时长、加班时长、总时长和冲突提示。
15. 点击“一键清空当前排班”可在二次确认后清空当前直播间、当前日期区间的所有班次；休假人员与休假备注会保留。
16. 在“业绩排名”的横向排班矩阵中录入每个班次的业绩金额；日期横向排列、班次纵向排列。同一金额完整计入该班主播和副播，并分别生成主播榜与副播榜。排名可快捷查看当前区间、近30天、近3个月或全部日期。

休假人员选择框支持连续多选。每次勾选后会自动保存并即时刷新冲突提示，但选择框会保持展开，方便继续选择其他人员。

数据会自动保存在当前浏览器中。建议定期使用“文件 → 导出 JSON 备份”保存完整备份；更换电脑或浏览器后，可通过“导入 JSON 备份”恢复。

“文件”菜单提供两类排班 Excel：

- “下载空白排班模板”根据当前 1–14 天日期区间、启用班组、人员、班次和直播间生成横向填写表。
- “导出可编辑排班模板”使用相同格式并预填已有排班，修改后可通过“导入排班模板”重新导入。
- “导出展示版排班表”生成适合查看、打印和分享的纵向七列表格，包含日期、账号、班次、班组、直播时间、出勤时间和直播时长；展示版不能重新导入。

业绩可通过“导出业绩表”修改后重新导入，也可以下载金额为空的固定模板。导入前会显示新增、更新、跳过、阻断错误和业务警告；确认后才会一次性写入并自动保存。

本版本附带 `三个月测试排班-V14.json`。需要重新载入示例数据时，点击“导入备份”选择该文件即可（导入会覆盖浏览器中的当前数据）。

## 数据说明

- 初始班次仍为主号早班 08:00–12:30、主号中班 13:00–17:30、主号晚班 19:00–23:30、副直播间班次 13:30–18:00；均可在“排班设置”修改。
- 初始每日最低目标为 4 班、18 小时，默认自动加班时长为 1.5 小时；三个值均可自定义。
- 自动排班先满足班次数，再满足总直播时长；不足的最后一段加班会按精确缺口生成，不会强制补满默认加班时长。
- 固定兼职班组任一成员当天休假时不会自动寻找替补，系统会显示红色警告。
- 排班直播不支持跨午夜；结束时间必须晚于开始时间。
- 出勤时间由直播开始时间自动确定：早于 11:00 对应 08:00–16:00，11:00–15:59 对应 11:00–19:00，16:00 及以后对应 16:00–23:30。直播和加班时间不得超出对应出勤区间。
- 同一人员重叠排班、主播副播选为同一人、休假当天仍被排班时都会显示警告。
- 删除人员或直播间只会移出未来选择列表，历史排班中的名称和账号快照会保留。
- 旧版 V1/V2/V3/V4 数据会自动升级到 V5，并在浏览器中保留升级前备份。
- V5 以“直播间 + 具体日期”保存排班，并加入全局动态班次、班组和最低目标配置；同一天从任何日期区间打开时都会显示同一份排班。
- CSV 文件带 UTF-8 BOM，可直接用中文 Excel 打开。
- Excel 导入导出使用工具内置组件处理真正的 `.xlsx` 文件，可完全离线运行。可编辑排班模板按日期横向排列，展示版排班表按日期纵向分组。
- 业绩按日期和班次保存在排班记录中，金额单位为人民币元，最多两位小数；主播和副播分别排名，同金额使用并列名次。
- 一键清空排班会同时清空对应班次业绩，休假人员与休假备注仍会保留。

## 文件

- `index.html`：页面入口
- `styles.css`：界面样式
- `logic.js`：日期、时长、统计和冲突逻辑
- `excel.js`：排班与业绩 Excel 生成、解析、校验和事务式合并
- `app.js`：页面交互和本地存储
