# 直播周排班工具

这是一个纯本地网页工具，用于按自然周安排主播和副播，并统计直播时长。

## 使用方法

1. 双击 `index.html`。
2. 使用顶部日期控件选择任意周。
3. 在“周排班”中选择主播、副播并设置直播时间。
4. 在“人员管理”中维护人员及其角色。
5. 在“时长统计”中查看主播时长、副播时长、总时长和冲突提示。

数据会自动保存在当前浏览器中。建议定期点击“导出备份”保存 JSON 文件；更换电脑或浏览器后，可通过“导入备份”恢复。

## 数据说明

- 早班默认时间：08:00–13:00
- 中班默认时间：13:00–18:00
- 晚班默认时间：18:30–23:30
- 结束时间早于开始时间时，按跨午夜直播计算。
- 同一人员的重叠排班会显示警告。
- CSV 文件带 UTF-8 BOM，可直接用中文 Excel 打开。

## 文件

- `index.html`：页面入口
- `styles.css`：界面样式
- `logic.js`：日期、时长、统计和冲突逻辑
- `app.js`：页面交互和本地存储
