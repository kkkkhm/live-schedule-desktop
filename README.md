# 直播周排班工具

这是一个纯本地网页工具，用于按自然周安排直播间、主播和副播，并分别统计普通直播时长、加班时长和总时长。

## 使用方法

1. 双击 `index.html`。
2. 使用顶部日期控件选择任意周。
3. 先在“直播间管理”中维护直播间名称和账号。
4. 在“周排班”标题右侧选择直播间；一整张周表只属于该直播间，切换直播间会切换到独立周表。
5. 在排班格中选择主播、副播并设置直播时间；三个“加班”行均可独立排班。
6. 在“历史记录”查看近三个月周表，可完整复制到新日期，或勾选“清空排班内容”建立空白周表。
7. 在“人员管理”中维护角色、正式/兼职状态，并可编辑、停用或删除。
8. 在最下方“休假人员”行按天多选休假人员。
9. 在“时长统计”中查看当前直播间的直播时长、加班时长、总时长和冲突提示。

数据会自动保存在当前浏览器中。建议定期点击“导出备份”保存 JSON 文件；更换电脑或浏览器后，可通过“导入备份”恢复。

## 数据说明

- 早班正常时间：08:00–12:30
- 中班正常时间：13:00–17:30
- 晚班正常时间：19:00–23:30
- 超出正常班时间的直播部分拆分到对应“加班”行统计。
- 三个加班行不预设时间，排入后全部计入“加班时长”。
- 结束时间早于开始时间时，按跨午夜直播计算。
- 同一人员重叠排班、主播副播选为同一人、休假当天仍被排班时都会显示警告。
- 删除人员或直播间只会移出未来选择列表，历史排班中的名称和账号快照会保留。
- 旧版 V1/V2 数据会自动升级到 V3，并在浏览器中保留升级前备份。
- 历史复制不会覆盖目标直播间已有排班，原历史记录始终保留。
- CSV 文件带 UTF-8 BOM，可直接用中文 Excel 打开。

## 文件

- `index.html`：页面入口
- `styles.css`：界面样式
- `logic.js`：日期、时长、统计和冲突逻辑
- `app.js`：页面交互和本地存储
